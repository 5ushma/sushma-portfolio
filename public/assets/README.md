# /public/assets

Drop your real files here. They are referenced from `src/data/content.ts`.

| File              | Used for                          | Referenced in `content.ts` |
| ----------------- | --------------------------------- | -------------------------- |
| `headshot.jpg`    | Hero portrait                     | `site.headshot`            |
| `resume_ATS.pdf`  | "Download CV" button              | `site.cvUrl`               |

- **Headshot:** add `headshot.jpg` here (recommended ~800×1000px, 4:5 portrait).
  Until you do, the Hero shows a styled initials placeholder automatically.
- **CV:** the "Download CV" button points to `resume_ATS.pdf`. A placeholder PDF
  ships here — overwrite it with your real ATS resume, keeping the same filename.
